# 借址租戶服務與合約呈現

本輪改善租戶詳情：以實際合約、服務期限及收費約定為主，聯絡人和承辦歷程移到後方；維持大字、深色、條列及可收合設計。教學影片不重製。

## 同業公開方案研究（2026-10-06）

- Have a Seat：https://17rent.com.tw/businessregistration/ — 一年和兩年方案，地址使用與郵件服務搭配。期限不能由一次付款推定。
- JR 商務中心：https://jr-business.com/pricing — 月繳、年繳和含一次性公司設立費的組合；同一套餐不同項目也可能有不同服務期間。
- 辰星商務中心：https://www.morning-stars.com.tw/virtual-office.html — 借址年費、首期押金和續約金額分列；郵件代收與通知屬方案服務，設立及記帳可另外合作。
- 安格斯：https://www.wannguo.com/virtual-office/ — 年約可含贈送期，付款及押金依合約約定。

以上只參考公開服務結構，未假稱取得同業內部 CRM 畫面或操作流程；不複製其價格或自動套入真實租戶。

## 已實作

1. 租戶清單從合約顯示實際起迄與狀態：未建合約、草稿、未開始、期間內、到期或終止。已成交／已建檔本身不代表借址服務有效。
2. 詳情先顯示登記據點與地址、起日、迄日（含當日）、合約類型、約定付款週期、本期總額（限財務可讀角色）、郵件代收與到期／續約提醒。
3. 合約類型：月約、年約、兩年約、自訂；付款週期：一次繳清、每月、每季、半年、每年、個別約定。兩者獨立，年約可以按月付款，贈送期以實際起迄為準。
4. 新建／續約可登記這些條件，續約沿用原條件或明確調整。月／年／兩年約提供曆月起迄建議，可覆寫實際日期。新合約未確認前為草稿。
5. 管理員可用版本及變更依據補登舊合約條件；保留實際操作人員，不修改原起迄、金額或收款。終止合約只讀。
6. 明確區分另案一次性設立／遷址服務與借址年約；第一期尚無獨立代辦／押金收費台帳，不能假裝已記帳。
7. 官網、商城、LINE OA／CRM 各列服務期間及收費狀態；未訂閱不產生假日期，舊預覽紀錄顯示實際期間並明示未開通。平台費、分潤仍 NULL／待議定，數位收費及功能開通仍封鎖。
8. 新增輕量服務摘要 API：最多 5 份代表合約、20 筆既有數位訂閱期間；完整歷史仍在維運台。租戶分頁在同一 SQL 帶出代表合約，不逐租戶查詢。
9. 新增 0006 migration：nullable 合約類型、付款週期、郵件服務欄位與查詢索引。舊值留 NULL，不自動當作年約／月繳；不刪除或重建資料。

## 收款行為與驗收界線

付款週期本輪是雙方約定的紀錄，不能當作自動月帳單或銀行扣款。現有應收仍按每份合約總額建一張台帳，人工收款可以分次登記。單張應收的付款期限是該應收的約定日期，未提供按期拆單、每月獨立到期／欠款或自動續約。這些後續工作須依實際付款排程另外實作，不能推定月繳客戶已欠整份年費。

押金、一次性代辦各自應收／退還、合約文件、遷出確認、按期排款、續約跟進名單／提醒及長期客戶回訪，保留為後續可驗收工作。現有工作台具有聯絡人、業務追蹤和服務歷程的 CRM 功能，但不代表租戶自用 CRM 已開通。既有 PLATFORM_BLUEPRINT.md 與後續數位需求完整保留。
