# 新增資料入口

總管理員可從下列入口開始操作，即使資料庫沒有客戶：
- 總覽／成交追蹤／工作聊天室：建立案件，同時新增企業與聯絡人，或沿用既有企業。
- 租戶管理：新增既有租戶。只作人工轉入建檔，不自動建立成交、收款、合約或功能權益；新洽談客戶仍使用案件成交轉租戶。
- 操作人員：新增姓名與業務／維運／財務分工。紀錄預設停用並標示待綁定登入；未完成企業 Access 身分綁定不得啟用或指派案件。此入口不自動寄邀請，正式帳號登入綁定仍須由管理員完成設定。
- 據點與方案：獨立入口新增登記據點與數位方案，不需要先有租戶。
- 租戶維運：先選租戶，再新增地址合約、數位訂閱、應收、收件與維運需求；按角色顯示合法操作。

新增資料均由後端使用 session 的 operator_id／actor_id 記錄，不能由客戶端指定角色或跨業者資料。既有租戶使用服務中租戶標示，避免將人工轉入冒稱案件已成交。資料名稱、聯絡方式及建檔依據不應出現在公開 PR 或程式碼。LINE、金流及 AI 狀態保持未串接／未啟用。
