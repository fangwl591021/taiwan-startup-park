## 預留的數位合作欄位
每家借址業者、每種數位服務各有一份預留資料。官網、商城、LINE OA 與 CRM 的合作平台商、平台費、平台端分潤比例、業者端分潤比例、結算基準、結算週期、生效日及議定文件／依據均為 NULL。狀態為 unagreed，畫面顯示待議定與空白停用欄位。NULL 不等於 0、0% 或免費，不使用前述說明中的示例比例作為預設。

比例後續以整數基點保存（10000 = 100%）；兩方比例若填入必須完整且合計 10000。未議定的紀錄不能包含任何商業條件。現在沒有填寫／核准 API，也沒有分潤計算、撥款或結算作業。欄位由業者管理員唯讀查看，API 依 session 的 operator_id 隔離；不能提交 operator_id 更改歸屬。

這些欄位先建立兩方合作結構，不代表已選定平台費、比例、收款方、稅務／發票責任或簽署協議。真正串接前須定義收款方、扣除項、退款／更正、當期標準快照、合作對象與結算對帳，再另行開放經授權的設定與核准流程。
