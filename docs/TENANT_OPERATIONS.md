# 第三輪：租戶維運與數位服務租用

本分支接續第二輪，保留原始 PLATFORM_BLUEPRINT.md 全文，不部署正式 Worker，也不對遠端資料庫執行遷移。所有預置企業、據點、價格及憑據均為虛構示範資料。

## 可操作範圍

- 業者據點與數位方案：業者隔離、方案停售／恢復；改價建立新方案，既有訂閱保留價格、天數與額度快照。
- 地址合約台帳：草稿、人工確認、終止、下一期續約。記錄期間、總額及確認依據；同租戶同據點有效期間不得重疊。這不是法律契約產生器或電子簽章。
- 應收與收退款：地址服務款、數位訂閱款分帳；商城商品款未開放。每個合約／訂閱期一張應收，可分次收款。不是電子發票或實際扣款。
- 收款不能超過應收餘額；退款必須對應同帳款原收款且不超過未退額。歷程不可更新或刪除，以新增退款紀錄更正。應收僅在淨實收為零時可作廢，作廢後不再收款，也不在原期重開應收。
- 信件包裹：收件、待領、自取、轉寄、退回；交付或退回需記錄依據。未串接物流、通知或簽收服務。
- 維運需求：建立、處理、解決、重開、結案；處理與結案有實際操作人員紀錄。
- 數位訂閱：待確認、試用、有效、暫停、恢復、取消、續訂。期限首末日均包含，依台北日期判斷。有效資格需期間內且試用中，或已確認且本期足額收款；退款後即重新計算資格。
- 後端權益檢查：不符資格回傳 403；商業資格符合但整合未完成回傳 503。所有模組 enabled=false、provisioning_status=not_connected；usage=null，額度只是方案快照，沒有假裝已計量或已開通。
- 退租或終止地址合約不刪除企業、聯絡人、數位訂閱或既有歷程。
- 新增操作的伺服器端身分歸屬、版本衝突及請求識別碼防重。財務與維運異動以原子批次及資料庫約束保障。

## 權限

| 操作 | 業者管理員 | 指派業務 | 指派維運 | 財務 |
| --- | --- | --- | --- | --- |
| 租戶可見範圍 | 本業者全部 | 自己負責案件的租戶 | 自己承辦租戶 | 本業者全部 |
| 據點與方案設定 | 可管理 | 唯讀 | 不含價格的唯讀 | 唯讀 |
| 合約、訂閱建立與續期 | 可 | 可 | 不可 | 不可 |
| 合約、訂閱狀態確認 | 可 | 不可 | 不可 | 不可 |
| 應收與收退款 | 可管理 | 應收摘要唯讀，不能看憑據 | 不提供 | 可管理 |
| 信件、維運需求 | 可管理 | 可管理 | 可管理 | 不提供 |

平台管理及企業端帳號在本輪仍未開放上述業者 API。跨業者或未指派資料回傳 404。操作人員、業者及金額來源由後端決定，不能由表單冒用。

## 資料與驗收

新增 migration 0003，保留 0001／0002、既有 LINE 訊息與身分流程。本地 SQLite 會依序套用；正式 D1 尚未套用。執行 npm ci、npm run typecheck、npm test、npm run worker:check 與 npm run test:e2e。測試涵蓋跨業者／指派隔離、帳款分類、版本競爭、重複請求、超收與超退、訂閱期間／資格／退款、信件交付與維運歷程。

案件上的舊 payment_status 是第一輪人工案件標記，不等於本輪應收台帳實收；不拿該標記抵充帳款或開通訂閱。收退款不可覆寫的規則限定財務台帳，並非對聊天室內容訂定無限保存政策。

## 保留後續需求

完整藍圖為產品方向來源。本輪尚未包含報價版本、正式契約文件上傳／簽署、租戶自助付款與發票、自動續扣／到期催收、分潤結算、商城商品金流、網站產生器、模組實際佈建、用量計量／超額限制、物流追蹤與通知、AI 分析或對話風控。LINE 程式基礎沿用第二輪，但本驗收環境未設定實際 OA；不寄出真實訊息。後續第三方服務、權限、留存和計價需另行實作與驗收，不因本台帳標記而視為完成。
